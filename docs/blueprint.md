# **App Name**: KhmerEZ

## Core Features:

- Unified Input Box: Simple, single-input text box for easy message entry in either English or Cambodian.
- AI-Powered Translation: Real-time translation tool between English and Cambodian using modal gemini-1.5 pro
- AI Text-to-Speech: Utilize gemini-1.5 pro to synthesize translated text into natural-sounding speech.
- Voice Recording: Record voice memos and automatically transcribe it.
- Voice Translation: Use modal gemini-1.5 pro to translate voice recordings into text and the opposite language.
- Speak button: Button to play the translated output. It should be clear and accessible

## Style Guidelines:

- Primary color: Calm blue (#64B5F6) to convey trust and ease of communication.
- Background color: Light gray (#ECEFF1), very low saturation.
- Accent color: Yellow (#FFEB3B), creating focus on translated text
- Body and headline font: 'PT Sans', a humanist sans-serif font, which will support readability of blocks of translated text as well as display the limited content elsewhere in the app.
- Simple, intuitive icons for translate and speak functions.
- Subtle transitions during translation and text-to-speech processes to enhance user experience.
